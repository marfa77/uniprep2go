## Gate tightening 2026-10-02

`audit-bank-quality.mjs` passed junk banks. New FAIL gates: template notes "Not the best answer here" / "the right answer is" / "answer to a different question"; boilerplate stem wrapper (`On the … Mock` / `Select the best answer.`); distractor = another item's correct answer (≥25 chars) > 5%. Near-dup stems: when both stems have ≤4 content words, digit-bearing tokens (equations, rule numbers) now count too, with Drill/Item/Variant N labels stripped — short equation stems ("If 4x - 7 = 21, what is the value of x?") no longer collide; Drill templates still flagged. Effect across banks: SAT 36 → 3 pairs, GRE 110 → 101, a handful of modifier / NFPA-number pairs elsewhere.
