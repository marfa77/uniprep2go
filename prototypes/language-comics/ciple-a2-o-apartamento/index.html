How this “best comic” pilot was built

  • Comprehensible input (~95%): short A2 dialogue, concrete nouns shown in art.
  • Pictures first, bubbles second: art has no baked-in text (AI text is unreliable).
  • Exam scenario: apartment viewing — CIPLE / daily-life Portuguese.
  • Adult tone: not kids’ manga; Lisbon azulejo visual identity.
  • Study layer after story: glossary → comprehension → Anki chunk list (no parallel EN during reading).

Study pack — O Apartamento

How to use (5 minutes): 1) Read the comic once. 2) Check the glossary only for stuck words. 3) Answer the 5 questions aloud. 4) Add the Anki chunks to your CIPLE deck.

2. Comprehension (answer in Portuguese)

  1. Como se chama a estudante?
  2. Quanto custa a renda por mês?
  3. As despesas estão incluídas?
  4. Há elevador no prédio?
  5. De que precisa o senhor Costa?
